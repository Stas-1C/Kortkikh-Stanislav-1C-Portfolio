Данный проект демонстрирует навыки доработки типовой конфигурации 1С:Управление торговлей 11 с использованием механизма расширений.
Все три задачи выполнены в рамках одного расширения.

1. Динамический индикатор просроченной задолженности
Форма документа «Заказ клиента» расширена: в неё добавлена обработка событий изменения реквизитов (&После).

Реализован серверный запрос к регистру накопления РасчетыСКлиентами с отбором по контрагенту и организации.

Текст и цвет декорации обновляются динамически без перезаписи типовой логики.

2. Картинка номенклатуры в форме списка
В форму списка справочника «Номенклатура» добавлено поле с картинкой.

Используется реквизит ФайлКартинки (тип СправочникСсылка.НоменклатураПрисоединенныеФайлы).

Картинка извлекается через стандартную функцию БСП РаботаСФайлами.ДанныеФайла(), что гарантирует совместимость с типовыми механизмами.

При отсутствии изображения ничего не отображается.

3. Загрузка цен с приоритетным поиском
В документ «Установка цен номенклатуры» добавлена кастомная кнопка, открывающая типовую форму загрузки из табличного документа.

Переопределён обработчик кнопки «Далее» (&Вместо): после стандартного сопоставления выполняется приоритетный поиск.

Приоритет поиска: Код → Артикул → Наименование.

Для поиска используются методы справочника Номенклатура: НайтиПоКоду, НайтиПоРеквизиту("Артикул", ...), НайтиПоНаименованию.

После успешного сопоставления товары переносятся в табличную часть документа.
